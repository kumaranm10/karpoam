# Karpoam · கற்போம்

Free, playful picture lessons for children aged 5–8 (K2, P1, P2): Maths, English, Science and Tamil.
Real-life examples, one sentence at a time, every sentence read aloud.

```bash
npm install
npm run dev      # http://localhost:4321
npm run check    # lesson gate
npm run build    # gate + static build into dist/
npm run verify   # every quality gate, same as CI
```

- Working on this repo (people or AI agents): read **AGENTS.md** first, then **TASKS.md**.
- Adding a lesson: **docs/LESSON_GUIDE.md**.
- Going live, costs and ads: **docs/DEPLOY.md**.
